# Unitree H1-2 asset attribution

The H1-2 handless MJCF and robot meshes in this folder are derived from Unitree Robotics’ `unitree_ros` repository, commit `ccfc6fd8430a17ba3dacef9a1e2faf64ff3b0aee`:

https://github.com/unitreerobotics/unitree_ros/tree/ccfc6fd8430a17ba3dacef9a1e2faf64ff3b0aee/robots/h1_2_description

The upstream work is distributed under the BSD 3-Clause License. See `LICENSE`. Meshes were decimated and exported as binary STL for browser delivery. The tennis racket mesh and court texture are retained from the prior LATENT demo assets. Motion on this page is reconstructed for the demo and is not a trained policy.
